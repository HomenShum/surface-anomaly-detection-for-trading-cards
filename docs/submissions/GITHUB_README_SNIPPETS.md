# GitHub README Snippets

## Short Description

AI-assisted trading-card condition catalog, DING detector, and timestamped evidence vault.

## Demo Command

```bash
pnpm demo:seed
pnpm dev:api
pnpm dev
```

Open `http://localhost:3000`, choose **Try sample card**, inspect DING boxes, save a catalog record, and run the before/after compare.

## Disclaimer

Card Condition Vault is not an official grading replacement. It creates condition evidence records, model-assisted annotations, and user-correctable reports.
