# Hackathon Submission

## Project

Card Condition Vault

## What It Does

The MVP lets a user scan or upload a trading card, run local analysis through FastAPI, review DING boxes, correct model output, save a catalog entry, and export evidence metadata with hashes and timestamps.

## Why It Matters

Collectors need a practical pre-shipping record. The product creates a defensible condition snapshot before a card leaves their possession.

## Demo

1. Open the app.
2. Click **Try sample card**.
3. View DING boxes and evidence hashes.
4. Save the catalog entry.
5. Run before/after comparison.
