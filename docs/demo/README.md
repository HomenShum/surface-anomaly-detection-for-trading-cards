# Card Condition Vault Demo

The demo fixtures model a small card review queue with declared grades, model
condition reads, confidence scores, reviewer status, and shareable real UI GIFs.

Run:

```bash
python scripts/demo/seed_card_condition_vault.py
pnpm demo:gifs
```

Then use `docs/demo/DEMO_STEPS.md` for the walkthrough and
`docs/qa/CHECKLIST.md` for acceptance checks.
