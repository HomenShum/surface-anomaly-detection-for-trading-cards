# Limitations

This method is verified for the alpha fixture pack only.

- It reduces false scratch calls on obvious holo glare, but it does not prove that a card has no surface damage.
- It still needs an alternate tilt frame for faint scratches that only become visible under one angle.
- It adds latency because the agent crops, checks glare, and reruns DING detection on a smaller region.
- It must not be used to claim an official grade or legal proof.
- It does not publish raw user images by default.
