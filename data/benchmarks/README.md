# Inspection Skill Benchmarks

Fixed fixtures + run records for the benchmark harness.

## Layout

```
benchmarks/
  fixtures/
    <fixture_name>.json    # input + ground truth, hand-authored
  runs/
    <skillId>_<ts>.json    # auto-generated by harness
```

## Fixture schema

```json
{
  "name": "...",
  "description": "...",
  "reportContext": {
    "cardId": "...",
    "reportSummary": "...",
    "conditionScore": 0-100,
    "surfaceScore": 0-100,
    "centeringScore": 0-100,
    "edgeScore": 0-100,
    "glareScore": 0..1,
    "finishType": "matte|glossy|holo|textured_foil|unknown",
    "findings": [{ type, confidence, severity, bbox, zone, sha256 }],
    "evidence": [{ role, sha256, path }]
  },
  "groundTruth": {
    "true_findings": [{ kind, region }],
    "forbidden_findings": [{ kind, region }],
    "expected_intents": ["..."]
  }
}
```

## Privacy

Fixtures are hand-authored — never derived from real user uploads. Bytes referenced
by `sha256` are placeholder hashes; they don't need to exist on disk.

## Running

```
POST /api/skills/benchmark { skillId: "..." }
```

Records land in `runs/`. Promotion endpoints read the most recent 5 runs to gate
canary/production transitions.
